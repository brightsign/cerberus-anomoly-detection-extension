Workflow (one file):
  1. Load the player's current config.json (scp it down first). Its existing zones appear as editable boxes.
  2. Draw / delete boxes to match the screens.
  3. Download config.json — the same file with your zones swapped in (everything else preserved).
  4. Copy it back and restart:
    scp config.json brightsign@PLAYER:/storage/sd/configs/config.json
    /var/volatile/bsext/ext_npu_anomaly/bsext_init restart
Boxes must lie fully inside the frame — out-of-bounds ROIs are dropped by the capture crop.
